# EasyUp Software Solution HQ - Operational Directives

- Rule 1: Human-in-the-Loop strictly enforced. Live customer communications, database migrations, financial disbursements, and production git releases require manual Go-Signal approval from Josiah.
- Rule 2: Single Source of Truth. Any corrections, bugs fixed, or updated company parameters are immediately appended here so every agent remembers and learns the fix.
